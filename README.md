# 🌐 Personal Portfolio Website

A clean, responsive personal portfolio website built with **HTML5, CSS3, and Bootstrap 5**.

The project presents a developer profile through dedicated sections for an introduction, skills, work, reviews, and contact information.

## ✨ Overview

This project is a beginner-friendly portfolio website focused on practicing **responsive web design, Bootstrap layout utilities, reusable UI sections, and clean page organization**.

### Main Sections

* 🏠 Hero / Home section
* 👨‍💻 About section
* 🛠️ Skills section
* 💼 Work / Web Development section
* ⭐ Client Review section
* 📩 Contact section
* 📱 Responsive Bootstrap navigation
* 🎨 Custom CSS styling

## 🎯 Key Features

### Responsive Navigation

Bootstrap's responsive navbar and collapse functionality provide a mobile-friendly navigation experience.

### Hero Section

A clean introduction area with a short description and call-to-action buttons.

### About Section

Introduces the developer profile and frontend development interests.

### Skills Section

Displays development-related skills in a card-based layout.

### Work Section

Highlights web development capabilities and technologies.

### Review Section

Displays sample client testimonials with ratings.

### Contact Section

Includes a simple contact form with:

* Name
* Email
* Address
* Phone Number

## ⚙️ Getting Started

### Clone the Repository

```bash
git clone https://github.com/ummehadidevs/html-css-responsive-111.git
```

### Open the Project

```bash
cd html-css-responsive-111
```

### Run Locally

No package installation is required because this is a static HTML/CSS project.

You can open `index.html` directly in your browser or use VS Code's **Live Server** extension.
